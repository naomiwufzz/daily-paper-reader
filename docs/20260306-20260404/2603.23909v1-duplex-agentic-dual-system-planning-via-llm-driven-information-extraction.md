## 摘要
虽然大语言模型（LLMs）为机器人任务规划提供了语义灵活性，但其易产生幻觉和逻辑不一致的特性限制了其在长程领域中的可靠性。为了弥合非结构化环境与严谨规划合成之间的差距，我们提出了 DUPLEX，这是一种代理式双系统神经符号架构，它将 LLM 严格限制在模式引导的信息抽取任务中，而非进行端到端规划或代码生成。在我们的框架中，前馈“快系统”利用轻量级 LLM 从自然语言中提取实体、关系等，并将其确定性地映射为经典符号规划器的规划领域定义语言（PDDL）问题文件。为了处理复杂或描述不足的场景，当且仅当规划失败时才会激活“慢系统”，利用求解器的诊断信息驱动高容量 LLM 进行迭代反思与修复。在 12 个经典及家庭规划领域的大量评估表明，DUPLEX 在成功率和可靠性方面均显著优于现有的端到端及混合 LLM 基准。这些结果证实，核心关键不在于提升 LLM 的规划能力，而在于将其限制在所擅长的结构化语义对齐任务上，并将逻辑规划合成交给符号规划器。

## Abstract
While Large Language Models (LLMs) provide semantic flexibility for robotic task planning, their susceptibility to hallucination and logical inconsistency limits their reliability in long-horizon domains. To bridge the gap between unstructured environments and rigorous plan synthesis, we propose DUPLEX, an agentic dual-system neuro-symbolic architecture that strictly confines the LLM to schema-guided information extraction rather than end-to-end planning or code generation. In our framework, a feed-forward Fast System utilizes a lightweight LLM to extract entities, relations etc. from natural language, deterministically mapping them into a Planning Domain Definition Language (PDDL) problem file for a classical symbolic planner. To resolve complex or underspecified scenarios, a Slow System is activated exclusively upon planning failure, leveraging solver diagnostics to drive a high-capacity LLM in iterative reflection and repair. Extensive evaluations across 12 classical and household planning domains demonstrate that DUPLEX significantly outperforms existing end-to-end and hybrid LLM baselines in both success rate and reliability. These results confirm that The key is not to make the LLM plan better, but to restrict the LLM to the part it is good at - structured semantic grounding - and leave logical plan synthesis to a symbolic planner.

### 论文总结：DUPLEX 代理式双系统规划架构

#### 1. 核心问题与整体含义（研究动机和背景）
在具身智能领域，长程任务规划（Long-horizon planning）要求极高的逻辑严谨性和物理约束遵循能力。传统符号规划器（如基于 PDDL 的求解器）虽然逻辑严密，但存在“知识获取瓶颈”，难以处理非结构化的现实环境。而大语言模型（LLM）虽具备常识和语义灵活性，但在直接生成规划时极易产生**幻觉、逻辑不一致及违反物理前提**等问题。
本文的核心动机在于：**不应强求 LLM 去做它不擅长的逻辑合成，而应将其限制在它擅长的“结构化语义对齐（信息抽取）”任务上**。通过将 LLM 与符号规划器深度耦合，解决 LLM 规划不可靠和 LLM+P 模式生成代码易碎的问题。

#### 2. 方法论：核心思想与技术细节
DUPLEX 提出了一种**代理式双系统神经符号架构**，模拟人类认知的“快慢思考”：

*   **快系统（Fast System - 前馈路径）：**
    1.  **引导式信息抽取（IE）：** 使用轻量级 LLM 根据预定义的 Schema（由 Domain PDDL 导出）从环境描述中提取实体、关系和状态（JSON 格式）。
    2.  **确定性映射：** 通过预编写的脚本将 JSON 数据填入 PDDL 模板，确保 100% 的语法正确性，避免 LLM 直接写代码带来的编译错误。
    3.  **符号求解：** 调用 Fast Downward 等经典规划器生成动作序列。
*   **慢系统（Slow System - 闭环反思）：**
    *   仅在快系统规划失败（如搜索失败或逻辑矛盾）时激活。
    *   **代理式反思：** 将规划器的错误诊断信息反馈给高能力 LLM（如 GPT-4o）。
    *   **迭代修复：** LLM 分析失败原因（如遗漏了“微波炉是关着的”这一隐性状态），修正 Problem PDDL 文件并重新尝试，直到成功。

#### 6. 主要结论与发现
*   **性能飞跃：** DUPLEX 在 IPC 领域达到 97.5% 的成功率（远高于 LLM-as-Planner 的 11.9% 和 LLM+P 的 71.9%）；在家庭领域达到 83.5% 的成功率。

#### 7. 优点
*   **架构解耦：** 将“语义理解”与“逻辑搜索”完美分离，发挥了神经和符号系统各自的优势。
*   **鲁棒性高：** 通过确定性映射消除了 PDDL 语法错误，通过慢系统解决了语义遗漏问题。
*   **效率优化：** 只有在必要时才调用昂贵的大模型进行反思，降低了常规任务的推理成本。

#### 8. 不足与局限
*   **依赖先验：** 系统仍假设可以获取人工编写的 Domain PDDL 文件（动作定义），这在完全未知的环境中可能受限。
*   **实时性挑战：** 慢系统的迭代反思循环会引入额外的延迟，可能不适用于对实时响应要求极高的动态控制任务。
*   **模态限制：** 目前主要依赖文本抽取，在视觉信息极其丰富且存在指代歧义的环境下，可能需要更强的多模态对齐能力。
