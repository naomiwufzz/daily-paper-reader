## 摘要
基于大语言模型（LLM）的自主智能体缺乏持久的程序性记忆：即使之前已经解决过结构完全相同的任务，它们仍会从头开始推导解决方案。我们提出了 APEX-EM，这是一种非参数化在线学习框架，它在不修改模型权重的情况下积累、检索和重用结构化程序计划。APEX-EM 引入了：(1) 一种结构化经验表示，编码了每次执行的完整程序-情境轨迹——包括规划步骤、中间产物、带有错误分析的迭代历史以及质量评分；(2) 一种“规划-检索-生成-迭代-摄取”（PRGII）工作流，其中任务验证器提供多维奖励信号；(3) 一种具有双重结果的经验记忆，采用结合了语义搜索、结构特征匹配和计划有向无环图（DAG）遍历的混合检索方式——从而实现在词汇无重叠但操作结构相似的任务之间进行跨领域迁移。成功的经验作为正向上下文示例；失败的经验则作为带有结构化错误标注的负面示例。我们使用 Claude Sonnet 4.5 和 Opus 4.5 在 BigCodeBench、KGQAGen-10k 和 Humanity's Last Exam (HLE) 上进行了评估。在 KGQAGen-10k 上，APEX-EM 达到了 89.6% 的准确率，而无记忆情况下为 41.3%（提升 48.3 个百分点），超过了真值检索（oracle-retrieval）的上限（84.9%）。在 BigCodeBench 上，其成功率从 53.9% 的基准提升至 83.3%（提升 29.4 个百分点），在骨干网络冻结的同等条件下，超过了 MemRL 11.0 个百分点的增益（注：我们的分析中对骨干网络的差异进行了控制）。在 HLE 上，实体图检索从 25.2% 提升至 48.0%（提升 22.8 个百分点）。消融实验表明，各组件的价值取决于具体任务：丰富的评判反馈对代码生成的影响微乎其微，但对结构化查询至关重要（提升 10.3 个百分点），而二元信号迭代可以部分补偿较弱的反馈。

## Abstract
LLM-based autonomous agents lack persistent procedural memory: they re-derive solutions from scratch even when structurally identical tasks have been solved before. We present \textbf{APEX-EM}, a non-parametric online learning framework that accumulates, retrieves, and reuses structured procedural plans without modifying model weights. APEX-EM introduces: (1) a \emph{structured experience representation} encoding the full procedural-episodic trace of each execution -- planning steps, artifacts, iteration history with error analysis, and quality scores; (2) a \emph{Plan-Retrieve-Generate-Iterate-Ingest} (PRGII) workflow with Task Verifiers providing multi-dimensional reward signals; and (3) a \emph{dual-outcome Experience Memory} with hybrid retrieval combining semantic search, structural signature matching, and plan DAG traversal -- enabling cross-domain transfer between tasks sharing no lexical overlap but analogous operational structure. Successful experiences serve as positive in-context examples; failures as negative examples with structured error annotations.   We evaluate on BigCodeBench~\cite{zhuo2025bigcodebench}, KGQAGen-10k~\cite{zhang2025kgqagen}, and Humanity's Last Exam~\cite{phan2025hle} using Claude Sonnet 4.5 and Opus 4.5. On KGQAGen-10k, APEX-EM achieves 89.6\% accuracy versus 41.3\% without memory (+48.3pp), surpassing the oracle-retrieval upper bound (84.9\%). On BigCodeBench, it reaches 83.3\% SR from a 53.9\% baseline (+29.4pp), exceeding MemRL's~\cite{memrl2025} +11.0pp gain under comparable frozen-backbone conditions (noting backbone differences controlled for in our analysis). On HLE, entity graph retrieval reaches 48.0\% from 25.2\% (+22.8pp). Ablations show component value is task-dependent: rich judge feedback is negligible for code generation but critical for structured queries (+10.3pp), while binary-signal iteration partially compensates for weaker feedback.

#### 1. 核心问题与整体含义（研究动机和背景）
LLM 智能体在执行任务时通常是“无状态”的：即使面对结构上几乎相同的任务，它们也会从头开始推理，无法复用之前的成功路径或避开已知的失败陷阱。现有的记忆机制（如 MemRL 或 RAG）大多存储扁平的文本摘要或简单的向量，丢失了任务执行中的**程序化结构**（如规划步骤、工具调用链、错误恢复路径）。此外，当任务描述在语义上差异很大但逻辑结构相似时（例如“查询体育数据”与“查询财务报表”），现有的语义检索方法往往失效。

#### 2. 方法论：核心思想与关键技术
APEX-EM 提出了一种**非参数化在线学习**框架，其核心在于通过**结构化程序-情境经验回放**（Structured Procedural-Episodic Experience Replay）来增强智能体。

*   **核心思想**：不修改模型权重，而是通过外部存储器积累结构化的执行轨迹，将成功经验作为正向示例，失败经验作为带错误标注的负向示例。
*   **关键技术细节**：
    *   **程序化知识图谱 (PKG)**：一种分层图结构，连接实体（Entity）、经验（Experience）、操作（Operation）和子任务。
    *   **结构化经验表示**：每个经验包含五层反射：目标反射（RG）、程序反射（RP，可复用的模板）、证据反射（RE）、错误注册表（Rerr）和补丁反射（Rpatch）。
    *   **PRGII 工作流**：
        1.  **Plan (规划)**：分解任务，提取“结构签名”（抽象操作序列）。
        2.  **Retrieve (检索)**：混合检索机制，结合语义搜索、**结构签名匹配**（利用最长公共子序列 LCS 算法）和图遍历。
        3.  **Generate (生成)**：基于检索到的正/负样本生成代码或查询。
        4.  **Iterate (迭代)**：通过环境反馈进行自我修正。
        5.  **Ingest (摄取)**：由 Teacher 模型评估质量，合格后存入 PKG。
*   **跨领域迁移**：通过匹配抽象的操作序列（如 `[实体解析 -> 时间过滤 -> 聚合]`），实现跨领域的知识复用。

#### 6. 主要结论与发现
*   **性能飞跃**：在 KGQA 任务上，APEX-EM 将准确率从 41.3% 提升至 89.6%（+48.3pp），甚至超过了真值检索的上限。在代码生成上提升了 29.4pp。
*   **任务依赖性**：消融实验发现，**高质量的评判反馈**对结构化查询（KGQA）至关重要，但对代码生成（BCB）影响较小（因为代码测试结果本身提供了强信号）。
*   **效率提升**：随着记忆的积累，智能体解决任务所需的平均迭代次数显著下降（KGQA 任务减少了约 40% 的推理步骤）。
*   **跨领域有效性**：结构签名匹配允许智能体在词汇完全不同的任务间迁移逻辑，解决了纯语义检索的局限。

#### 7. 优点
*   **结构化程度极高**：相比之前的扁平化记忆，PKG 能够捕捉因果链和程序逻辑。
*   **双结果学习**：显式利用失败经验作为“护栏”，防止智能体重复同样的错误。
*   **非参数化优势**：无需微调模型即可实现持续学习，避免了灾难性遗忘，且具备完全的可审计性。
*   **效率与性能并重**：不仅提高了成功率，还通过减少迭代次数降低了推理成本。

#### 8. 不足与局限
*   **分类体系依赖**：结构签名的分类法（Taxonomy）目前仍需人工设计，可能限制了其在全新领域自动扩展的能力。
*   **Judge 模型依赖**：系统高度依赖一个更强大的“老师”模型（如 Opus 4.5）来生成高质量反馈，若老师模型存在偏见或错误，会污染记忆。
*   **理论保证缺失**：虽然实验效果显著，但作为一种非参数化方法，缺乏像强化学习那样的收敛性形式化证明。
*   **实时性挑战**：随着知识图谱（PKG）的无限增长，复杂的图遍历和混合检索可能会带来延迟挑战。
