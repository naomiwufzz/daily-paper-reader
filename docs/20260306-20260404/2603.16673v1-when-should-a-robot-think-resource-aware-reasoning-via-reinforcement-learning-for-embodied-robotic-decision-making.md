## 摘要
具身机器人系统日益依赖基于大语言模型（LLM）的智能体，在与环境交互过程中支持高层推理、规划和决策。然而，调用 LLM 推理会引入显著的计算延迟和资源开销，这可能中断动作执行并降低系统可靠性。过度推理可能会延迟动作，而推理不足则往往导致决策错误和任务失败。这为具身智能体提出了一个根本性问题：智能体何时应该推理，何时应该行动？在这项工作中，我们提出了 RARRL（基于强化学习的资源感知推理），这是一个用于具身智能体资源感知编排的分层框架。RARRL 并非学习底层控制策略，而是学习一种运行在智能体决策层的高层编排策略。该策略使智能体能够根据当前观测、执行历史和剩余资源，自适应地确定是否调用推理、采用哪种推理角色以及分配多少计算预算。大量实验（包括使用源自 ALFRED 基准测试的经验延迟数据进行的评估）表明，与固定或启发式推理策略相比，RARRL 在降低执行延迟和增强鲁棒性的同时，一致地提高了任务成功率。这些结果表明，自适应推理控制对于构建可靠且高效的具身机器人智能体至关重要。

## Abstract
Embodied robotic systems increasingly rely on large language model (LLM)-based agents to support high-level reasoning, planning, and decision-making during interactions with the environment. However, invoking LLM reasoning introduces substantial computational latency and resource overhead, which can interrupt action execution and reduce system reliability. Excessive reasoning may delay actions, while insufficient reasoning often leads to incorrect decisions and task failures. This raises a fundamental question for embodied agents: when should the agent reason, and when should it act? In this work, we propose RARRL (Resource-Aware Reasoning via Reinforcement Learning), a hierarchical framework for resource-aware orchestration of embodied agents. Rather than learning low-level control policies, RARRL learns a high-level orchestration policy that operates at the agent's decision-making layer. This policy enables the agent to adaptively determine whether to invoke reasoning, which reasoning role to employ, and how much computational budget to allocate based on current observations, execution history, and remaining resources. Extensive experiments, including evaluations with empirical latency profiles derived from the ALFRED benchmark, show that RARRL consistently improves task success rates while reducing execution latency and enhancing robustness compared with fixed or heuristic reasoning strategies. These results demonstrate that adaptive reasoning control is essential for building reliable and efficient embodied robotic agents.

*   **研究动机**：现有的系统通常采用固定频率或简单的启发式规则来决定何时调用 LLM。这种“盲目推理”会导致两个极端：一是过度推理造成动作延迟，影响实时性；二是推理不足导致决策错误，引发任务失败。
*   **核心问题**：机器人如何在有限的计算预算和时间约束下，自适应地平衡“思考（推理）”与“行动（执行）”的时机？

### 2. 方法论：RARRL 框架
论文提出了 **RARRL（Resource-Aware Reasoning via Reinforcement Learning）**，一种基于强化学习的资源感知编排框架。

*   **核心思想**：将推理过程视为一种“昂贵的动作”。在决策层引入一个 RL 策略（Orchestrator），由它来决定当前步骤是直接执行动作（ACT），还是先进行推理（THINK）。
*   **关键技术细节**：
    *   **状态空间 ($s_t$)**：整合了当前环境观测 ($o_t$)、剩余资源/预算 ($b_t$) 以及执行历史 ($h_t$)。
    *   **动作空间 ($a_t$)**：包括直接执行高层动作，或调用不同角色（如 Planner 规划者、Verifier 验证者）及不同计算预算（Token 限制）的推理模块。
    *   **奖励函数 ($r_t$)**：设计为 $r_t = r_{task} - \lambda \cdot \delta_t - \mu \cdot \text{failure}$。其中 $r_{task}$ 是任务成功奖励，$\delta_t$ 是执行延迟惩罚，$\mu$ 是动作失败惩罚。通过调节 $\lambda$ 平衡效率与成功率。
    *   **算法流程**：使用 **PPO（Proximal Policy Optimization）** 算法训练编排策略。策略输出三个维度：(1) ACT vs THINK 的概率；(2) 推理角色的选择；(3) 计算预算等级（如 Token 上限）。

### 6. 主要结论与发现
*   **性能提升**：RARRL 在任务成功率上接近“全量推理”，但在 **Token 消耗上降低了 60% 以上**，显著减少了端到端延迟。
*   **自适应性**：RL 策略学会了在复杂阶段（如识别物体）多思考，在常规阶段（如路径导航）直接行动。
*   **鲁棒性**：在面对计算资源突然受限（Budget Shock）时，RARRL 能迅速切换到“轻量化”模式，而启发式方法往往会因为资源耗尽而崩溃。
*   **性能天花板**：实验证明，编排策略的上限受限于底层执行器和推理器的强度，但 RARRL 能比其他策略更接近这一天花板。

### 7. 优点
*   **模块化设计**：将“编排”与“控制”解耦，无需修改底层的感知或电机控制，易于集成到现有机器人框架中。
*   **资源感知**：显式地将“剩余预算”作为状态输入，使智能体具备了类似人类的“量入为出”的决策能力。
*   **高效训练**：通过在抽象任务上训练并迁移到物理模拟器，解决了 RL 训练样本效率低的问题。

### 8. 不足与局限
*   **抽象与现实的差距**：虽然在 ALFRED 中进行了验证，但抽象任务模型可能无法完全捕捉真实物理世界中的所有噪声和不确定性。
*   **LLM 依赖性**：编排策略的效果高度依赖于预定义的推理角色（Planner/Verifier）的质量。
*   **奖励函数调优**：$\lambda$ 和 $\mu$ 等超参数需要针对不同任务进行手动微调，以达到理想的效率-性能平衡点。
*   **应用限制**：目前主要针对高层逻辑决策，对于需要极高频率反馈的底层闭环控制（如毫秒级避障），该框架的适用性尚未讨论。
