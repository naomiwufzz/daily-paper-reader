## 摘要
在动态开放世界环境中，自主智能体经常会遇到阻碍其制定实现目标之规划的新奇事物。具体而言，当机器人的规划领域缺乏使其能够与环境中新奇对象进行适当交互的算子时，传统的符号规划器将无法生成规划。我们提出了一种神经符号架构，该架构集成了符号规划、强化学习和大语言模型 (LLM)，以学习如何处理新奇对象。特别地，我们利用 LLM 的常识推理能力来识别缺失的算子，利用符号 AI 规划器生成规划，并编写奖励函数以引导强化学习智能体学习新识别算子的控制策略。我们的方法在连续机器人领域的算子发现和算子学习方面均优于现有最先进的方法。

## Abstract
In dynamic open-world environments, autonomous agents often encounter novelties that hinder their ability to find plans to achieve their goals. Specifically, traditional symbolic planners fail to generate plans when the robot's planning domain lacks the operators that enable it to interact appropriately with novel objects in the environment. We propose a neuro-symbolic architecture that integrates symbolic planning, reinforcement learning, and a large language model (LLM) to learn how to handle novel objects. In particular, we leverage the common sense reasoning capability of the LLM to identify missing operators, generate plans with the symbolic AI planner, and write reward functions to guide the reinforcement learning agent in learning control policies for newly identified operators. Our method outperforms the state-of-the-art methods in operator discovery as well as operator learning in continuous robotic domains.

*   **核心痛点**：
    1.  **规划失效**：传统符号规划器因缺乏针对新物体的动作算子（Operators）而无法生成路径。
    2.  **探索低效**：传统的强化学习（RL）在连续动作空间中寻找新动作的控制策略时，由于奖励稀疏，探索效率极低。
*   **研究目标**：构建一个能够自动识别缺失算子、生成规划并快速学习新技能的闭环系统，使机器人具备应对未知环境的自适应能力。

### 2. 方法论
论文提出了一种名为 **“计划-学习-执行”（Plan-Learn-Execute）** 的循环架构，核心技术包括：
*   **混合 LLM-符号规划（Hybrid LLM-Symbolic Planning）**：
    *   当符号规划器报错时，系统将当前状态、目标和新物体信息输入 LLM（使用 GPT-o3）。
    *   LLM 利用常识推理建议缺失的算子（包括参数、前置条件和有序的效果）。
    *   使用符号搜索算法（BFS）验证添加新算子后是否能找到通往目标的路径。
*   **LLM 引导的强化学习（LLM-guided RL）**：
    *   **奖励函数生成**：利用 LLM（使用 GPT-o4-mini）根据算子定义自动编写 Python 形式的密集奖励函数（Reward Shaping）。
    *   **子目标课程学习**：将算子的效果分解为多个子目标，分阶段训练 PPO（Proximal Policy Optimization）智能体。
    *   **遗传消除策略**：并行启动多个带有不同奖励函数候选的 RL 智能体，定期剔除表现最差的候选者，以应对 LLM 生成代码可能存在的错误或低效问题。

### 3. 实验设计
*   **实验场景**：在 `mimicgen` 连续机器人操纵仿真环境中设置了四个难度递增的任务：

    2.  **Nut Assembly (Medium)**：需学会从新型圆柱上取下螺母。
    3.  **Coffee-Box (Medium)**：咖啡胶囊在盒子里，需学会从盒中取出。
    4.  **Coffee-Drawer (Hard)**：胶囊在关闭的抽屉里，需学会“开抽屉”和“从抽屉取物”。
*   **Benchmark 与对比方法**：
    *   **Operator Discovery (OD)**：传统的通过随机探索发现可规划状态的方法。
    *   **LEAGUE-Sparse (LS)**：仅在完成任务时给予稀疏奖励的基准。
    *   **Reward Machine (RM)**：仅提供基于符号子目标的阶段性奖励，但不含 LLM 生成的密集奖励。

### 5. 实验数量与充分性
*   **实验规模**：每个任务均运行了 **10 个随机种子**。
*   **评估指标**：算子成功率（Success Rate）和任务完成进度（Progress）。
*   **充分性评价**：
    *   实验涵盖了从简单到极难（随机探索几乎不可能成功）的梯度。

### 6. 主要结论与发现
*   **算子识别**：LLM 能够准确识别缺失的算子定义，成功率远高于传统的算子发现方法。
*   **学习效率**：LLM 引导的密集奖励函数使 RL 智能体在所有任务中均达到了 90% 以上的成功率，而基准方法在 Medium 和 Hard 任务中几乎完全失败。
*   **鲁棒性**：通过并行采样多个奖励函数并进行“优胜劣汰”，系统能够有效克服 LLM 偶尔生成的错误代码。

### 7. 优点
*   **神经符号结合**：巧妙地将 LLM 的常识推理、符号规划的逻辑严谨性以及 RL 的底层控制能力结合在一起。
*   **自动化程度高**：实现了从发现问题（规划失败）到解决问题（学习新技能）的全自动化，无需人工干预定义奖励。
*   **解决冷启动问题**：通过 LLM 引导，解决了 RL 在高维连续空间中“大海捞针”式的探索难题。

### 8. 不足与局限
*   **感知假设**：假设机器人拥有完美的谓词检测能力（如能自动检测 `open(drawer)`），未考虑视觉感知误差。
*   **谓词限制**：系统目前只能在现有的谓词集合内定义新算子，无法自主发明全新的谓词（Predicates）。
*   **Sim-to-Real**：实验全部在仿真中完成，尚未在物理机器人上验证现实环境中的噪声和动力学差异。
