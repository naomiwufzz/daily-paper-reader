## 摘要
数据产品通过提供支持性资产（例如可利用数据回答的示例“问题-SQL”对，或数据库表上的视图），使终端用户能够获得关于其数据的更深入见解。然而，生产有用的数据产品具有挑战性，通常需要领域专家手工构建支持性资产。我们提出了一个系统，通过在持续优化循环中运行的专业化 AI 智能体，实现数据产品改进的自动化。通过挖掘问题、监控多维质量指标以及支持人机回环（human-in-the-loop）控制，该系统将数据转化为可观测且可精炼的资产，在自动化与信任及监管之间取得了平衡。

## Abstract
Data products enable end users to gain greater insights about their data by providing supporting assets, such as example question-SQL pairs which can be answered using the data or views over the database tables. However, producing useful data products is challenging, and typically requires domain experts to hand-craft supporting assets. We propose a system that automates data product improvement through specialized AI agents operating in a continuous optimization loop. By surfacing questions, monitoring multi-dimensional quality metrics, and supporting human-in-the-loop controls, it transforms data into observable and refinable assets that balance automation with trust and oversight.

### 2. 论文提出的方法论
系统采用两层架构（前端连接与后端处理），核心思想是**基于合同（Contract-aware）的闭环优化**：
*   **状态管理器（State Manager）**：维护数据产品的全局状态，包括架构元数据、问题映射、SQL 版本、答案置信度及视图定义。
*   **质量指标管理**：定义并跟踪表/列覆盖率、查询速度、复杂度及准确性。采用事件驱动机制，当数据状态改变时，通过依赖图自动重新计算相关指标。
*   **智能体编排层（核心流程）**：
    1.  **Planner Agent（规划智能体）**：作为决策核心，对比当前指标与目标（合同），识别影响最大的行动（如：若表覆盖率低，则触发问题生成）。
    2.  **Input Planner Agent（输入规划智能体）**：校准工具参数。例如，根据未覆盖表的数量动态决定生成 20 个还是 80 个问题，以平衡成本与效率。
    3.  **Specialized Agents（专业智能体）**：执行具体任务，包括问题生成（QUIS）、Text-to-SQL、问题聚类、视图创建等。
    4.  **持续循环**：执行后重新计算指标，并将结果提交至 Git 进行版本控制，直到达到预设目标或无法进一步优化。
