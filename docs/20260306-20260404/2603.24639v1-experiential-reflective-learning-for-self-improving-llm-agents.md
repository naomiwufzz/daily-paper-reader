## 摘要
大语言模型（LLMs）的最新进展使得开发能够进行复杂推理和多步问题解决的自主智能体成为可能。然而，这些智能体难以适应特定环境，且未能利用过去的交互经验，无论积累了多少经验，在面对新任务时往往都从零开始。我们提出了经验反思学习（ERL），这是一个简单的自我改进框架，通过经验学习实现快速的环境适应。ERL 通过反思任务轨迹和结果来生成启发式策略，捕捉可跨任务迁移的实践经验。在测试阶段，系统根据当前任务检索相关的启发式策略，并将其注入智能体的上下文以指导执行。在 Gaia2 基准测试中，ERL 的成功率比 ReAct 基线提高了 7.8%，在任务完成的可靠性方面有显著提升，并优于先前的经验学习方法。通过系统的消融实验，我们发现选择性检索至关重要，且启发式策略比少样本轨迹提示提供了更具迁移性的抽象。这些结果表明，通过反思单次尝试的经验来提取可迁移的启发式策略，能够实现有效的智能体自我改进。

## Abstract
Recent advances in large language models (LLMs) have enabled the development of autonomous agents capable of complex reasoning and multi-step problem solving. However, these agents struggle to adapt to specialized environments and do not leverage past interactions, approaching each new task from scratch regardless of their accumulated experience. We introduce Experiential Reflective Learning (ERL), a simple self-improvement framework that enables rapid environment adaptation through experiential learning. ERL reflects on task trajectories and outcomes to generate heuristics, capturing actionable lessons that transfer across tasks. At test time, relevant heuristics are retrieved based on the current task and injected into the agent's context to guide execution. On the Gaia2 benchmark, ERL improves success rate by 7.8% over a ReAct baseline, with large gains in task completion reliability, and outperforms prior experiential learning methods. Through systematic ablations, we find that selective retrieval is essential and that heuristics provide more transferable abstractions than few-shot trajectory prompting. These results demonstrate that reflecting on single-attempt experiences to extract transferable heuristics enables effective agent self-improvement.

### 1. 核心问题与研究动机
*   **核心问题**：现有的 LLM 智能体（Agents）在面对复杂任务时，往往缺乏“经验积累”能力。即使在同一环境中多次操作，它们通常也会像第一次接触环境一样从零开始，无法利用过去的成功或失败经验来优化当前的决策。
*   **研究背景**：虽然微调（Fine-tuning）可以实现环境适应，但其资源消耗大、不支持闭源模型且难以实现持续学习。现有的经验学习方法（如 ExpeL、AutoGuide）通常需要对同一任务进行多次尝试（Rollouts）来对比成功与失败，这在实际部署中（任务不可重复执行）往往不可行，且随着经验增加，上下文管理变得低效。

### 2. 方法论：经验反思学习 (ERL)
ERL 的核心思想是将单次任务的执行轨迹转化为高层次、可迁移的“启发式策略（Heuristics）”，并在新任务中按需检索。
*   **启发式生成（Heuristic Generation）**：
    *   智能体完成任务后，无论成功还是失败，都会对执行轨迹进行反思。
    *   生成结构化的启发式知识，包含：**分析**（识别导致成功或失败的关键点）和**学习指南**（明确触发条件和建议的操作步骤，例如：“当发送邮件给日历参与者时，先通过通讯录工具解析姓名”）。
*   **检索增强执行（Retrieval-Augmented Execution）**：
    *   面对新任务时，使用 LLM 作为评分器，从经验池中筛选出最相关的 $k$ 个启发式策略。
    *   评分标准基于任务描述的相似性、经验的多样性以及指南内容的丰富度。
    *   将选中的策略注入智能体的系统提示词（System Prompt）中，指导其 ReAct 推理循环。

### 6. 主要结论与发现

*   **可靠性增强**：ERL 在 Pass^3 指标上提升显著（执行类任务 +8.3%，搜索类任务 +10.6%），说明经验能让智能体表现更稳定。
*   **抽象优于原始数据**：启发式策略比原始轨迹（Few-shot）更具迁移性，且在相同的 Token 预算下表现更好。

*   **检索至关重要**：简单的随机选择或基于嵌入的检索效果不如基于 LLM 的语义检索。

### 7. 优点与亮点
*   **单次学习能力**：不需要像先前方法那样对同一任务进行多次尝试或构建对比对，更符合实际部署场景。
*   **高迁移性**：将具体的工具调用细节抽象为通用的策略指南，能够跨任务解决类似逻辑的问题。
*   **即插即用**：不需要微调模型，通过纯 Prompt 工程实现自我改进，适用于闭源模型。

### 8. 不足与局限
*   **用户协作挑战**：在 $\tau^2$-bench 的电信领域表现不佳，说明该方法在处理具有高度随机性的人机协作策略时仍有局限。
