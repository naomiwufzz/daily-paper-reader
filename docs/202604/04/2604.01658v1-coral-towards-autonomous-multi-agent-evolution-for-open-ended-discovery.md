## 摘要
基于大语言模型（LLM）的演化是开放式发现的一种极具前景的方法，这类发现的进展需要持续的搜索和知识积累。现有方法仍严重依赖固定的启发式方法和硬编码的探索规则，这限制了 LLM 智能体的自主性。我们提出了 CORAL，这是首个针对开放式问题的自主多智能体演化框架。CORAL 摒弃了僵化的控制，转而采用长期运行的智能体，通过共享持久化内存、异步多智能体执行和基于心跳的干预来进行探索、反思和协作。它还提供了实用的安全保障措施，包括隔离的工作空间、评估器分离、资源管理以及智能体会话和健康管理。在多样化的数学、算法和系统优化任务上的评估结果显示，CORAL 在 10 个任务上刷新了当前最佳（SOTA）结果，与固定演化搜索基准相比，其改进率提高了 3 到 10 倍，且评估次数大幅减少。在 Anthropic 的内核工程任务中，四个协同演化的智能体将已知最佳分数从 1363 个周期提升至 1103 个周期。机制分析进一步表明，这些收益源于知识重用以及多智能体的探索与通信。总之，这些结果表明，更强的智能体自主性和多智能体演化可以显著提升开放式发现的能力。代码已在 https://github.com/Human-Agent-Society/CORAL 开源。

## Abstract
Large language model (LLM)-based evolution is a promising approach for open-ended discovery, where progress requires sustained search and knowledge accumulation. Existing methods still rely heavily on fixed heuristics and hard-coded exploration rules, which limit the autonomy of LLM agents. We present CORAL, the first framework for autonomous multi-agent evolution on open-ended problems. CORAL replaces rigid control with long-running agents that explore, reflect, and collaborate through shared persistent memory, asynchronous multi-agent execution, and heartbeat-based interventions. It also provides practical safeguards, including isolated workspaces, evaluator separation, resource management, and agent session and health management. Evaluated on diverse mathematical, algorithmic, and systems optimization tasks, CORAL sets new state-of-the-art results on 10 tasks, achieving 3-10 times higher improvement rates with far fewer evaluations than fixed evolutionary search baselines across tasks. On Anthropic's kernel engineering task, four co-evolving agents improve the best known score from 1363 to 1103 cycles. Mechanistic analyses further show how these gains arise from knowledge reuse and multi-agent exploration and communication. Together, these results suggest that greater agent autonomy and multi-agent evolution can substantially improve open-ended discovery. Code is available at https://github.com/Human-Agent-Society/CORAL.

在科学发现和系统优化等“开放式发现”任务中，目标明确但最优解未知（如编写最高效的 GPU 内核）。现有的基于大语言模型（LLM）的进化搜索方法（如 FunSearch, AlphaEvolve）通常将 LLM 嵌入在固定的、硬编码的循环中，由外部算法决定何时变异、选择哪些父代以及如何更新种群。这种**“固定进化搜索”**限制了智能体的自主性，使其无法根据反馈灵活调整策略或积累长程知识。论文的核心动机是探索：如果将进化算法的决策权（检索、提议、评估、更新）完全交给自主智能体，并引入多智能体协作，是否能产生更强的发现能力。

#### 2. 方法论：核心思想与关键技术
CORAL 框架将进化过程从“固定算法驱动”转变为“自主智能体驱动”，其核心包含三个机制：
*   **共享持久内存（Shared Persistent Memory）**：采用类文件系统的结构，分为 `attempts/`（历史尝试与评分）、`notes/`（观察与反思笔记）和 `skills/`（可重用的代码片段或工具）。智能体可以自主读写这些内容，实现知识的跨时间、跨个体积累。
*   **异步多智能体组织**：多个智能体在隔离的工作区（Worktrees）中并行运行。它们不直接通信，而是通过共享内存进行“间接协作”（Stigmergy），例如一个智能体可以基于另一个智能体的高分代码进行改进，或参考其失败笔记以避坑。
*   **心跳机制（Heartbeat-based Interventions）**：为了防止智能体陷入局部最优或忘记总结，系统会定期触发三种干预：
    1.  **反思（Reflect）**：每步评估后记录笔记。
    2.  **整合（Consolidate）**：定期梳理笔记并提炼技能。
    3.  **重定向（Pivot）**：在性能停滞时强制智能体尝试全新方向。
*   **算法流程**：智能体自主执行“检索 -> 计划 -> 编码 -> 本地测试 -> 提交评估 -> 更新内存”的循环，而非被动等待外部指令。

*   **实验规模**：涵盖了 11 个基准任务和 2 个极具挑战性的压力测试，每项实验均进行 **4 次独立重复实验**并取平均值。
*   **消融实验**：专门设计了消融实验来验证“知识积累”和“协同进化”的必要性，对比了“有无笔记/技能”以及“多智能体协同 vs. 4 倍算力的单智能体”。

#### 6. 主要结论与发现
*   **刷新 SOTA**：CORAL 在 11 个任务中的 10 个取得了最佳结果，并在 8 个任务上创造了新的 SOTA。
*   **高效性**：相比固定进化方法，CORAL 的改进率（有效尝试占比）高出 **3-10 倍**，且达到相同分数所需的评估次数大幅减少。
*   **压力测试突破**：在 Anthropic 内核工程任务中，将已知最佳纪录从 1363 周期优化至 **1103 周期**（提升 20%）。
*   **协同效应**：多智能体协同的效果优于单纯增加计算资源的独立单智能体，证明了知识共享和多样化探索的价值。

#### 7. 优点（亮点）
*   **范式转移**：从“LLM 作为变异算子”提升到“LLM 作为自主进化管理者”，极大地释放了智能体在复杂搜索空间中的潜力。
*   **长程记忆**：通过结构化的文件系统（笔记、技能）解决了 LLM 在长程任务中容易遗忘或重复错误的问题。
*   **系统完备性**：不仅提出了算法，还实现了包含隔离工作区、心跳干预、实时监控 UI 在内的完整框架。

#### 8. 不足与局限
*   **模型依赖性**：CORAL 高度依赖强大的基座模型（如 Claude Opus 4.6），在弱模型上的表现尚未充分验证，且本地部署成本较高。
*   **初始化同质化**：目前所有智能体初始化相同，缺乏角色分工（如专家、评论家等）的异质性。
*   **评估器依赖**：框架假设存在一个定义明确的评估器（Grader），但在许多现实科学问题中，评估器本身可能是不完整或模糊的。
*   **搜索成本**：虽然评估次数减少，但由于智能体每步都要进行推理和反思，单次尝试的时间和 Token 成本高于简单的变异方法。
