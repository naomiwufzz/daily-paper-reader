## 摘要
随着大语言模型（LLM）智能体从简短、静态的问题解决转向在动态环境中执行复杂的长程任务，在任务执行过程中处理用户中断（如增加需求或修改目标）的能力正成为实际部署的核心要求。然而，现有的基准测试在很大程度上假设智能体行为是不受干扰的，或者仅在简短、无约束的语言任务中研究中断。在本文中，我们首次对长程、基于环境的网页导航任务中的可中断智能体进行了系统研究，在这些任务中，动作会引起持久的状态变化。我们形式化了三种现实的中断类型，包括增加、修改和撤回，并推出了 InterruptBench，这是一个源自 WebArena-Lite 的基准测试，在严格的语义约束下合成高质量的中断场景。利用统一的中断模拟框架，我们在单轮和多轮中断设置下评估了六种强大的 LLM 骨干模型，分析了它们在适应更新意图方面的有效性以及从任务中期变化中恢复的效率。我们的结果表明，在长程智能体任务中有效且高效地处理用户中断，对于强大的大规模 LLM 来说仍然具有挑战性。代码和数据集可在 https://github.com/HenryPengZou/InterruptBench 获取。

## Abstract
As LLM agents transition from short, static problem solving to executing complex, long-horizon tasks in dynamic environments, the ability to handle user interruptions, such as adding requirement or revising goals, during mid-task execution is becoming a core requirement for realistic deployment. However, existing benchmarks largely assume uninterrupted agent behavior or study interruptions only in short, unconstrained language tasks. In this paper, we present the first systematic study of interruptible agents in long-horizon, environmentally grounded web navigation tasks, where actions induce persistent state changes. We formalize three realistic interruption types, including addition, revision, and retraction, and introduce InterruptBench, a benchmark derived from WebArena-Lite that synthesizes high-quality interruption scenarios under strict semantic constraints. Using a unified interruption simulation framework, we evaluate six strong LLM backbones across single- and multi-turn interruption settings, analyzing both their effectiveness in adapting to updated intents and their efficiency in recovering from mid-task changes. Our results show that handling user interruptions effectively and efficiently during long-horizon agentic tasks remains challenging for powerful large-scale LLMs. Code and dataset are available at https://github.com/HenryPengZou/InterruptBench.

随着大语言模型（LLM）智能体从简单的静态任务转向复杂的**长程（Long-Horizon）**任务，现实部署中的一个核心挑战浮出水面：用户往往会在任务执行中途改变主意（如增加需求、修正错误或撤回指令）。现有的智能体基准测试（如 WebArena）大多假设任务意图是静态且不可中断的，而现有的少量关于“中断”的研究仅限于短程、无环境约束的纯语言任务。
本研究旨在填补这一空白，首次系统性地探讨了在具有**持久环境状态变化**的网页导航场景中，智能体如何应对动态的用户干预。

#### 2. 方法论：核心思想与技术细节
论文提出了一个名为 **InterruptBench** 的基准测试框架，其核心思想是通过模拟真实的人机交互动态来评估智能体的适应能力。
*   **三种中断场景形式化**：
    *   **增加 (Addition)**：用户在初始简略指令基础上补充新要求。
    *   **修正 (Revision)**：用户纠正初始指令中的错误信息（如日期、地点）。
    *   **撤回 (Retraction)**：用户要求移除之前设定的某些约束或细节。
*   **高质量数据合成管线**：基于 WebArena-Lite，利用 LLM 合成初始查询和中断消息，并遵循三个严格约束：**地标一致性**（最终意图与原任务一致）、**必要性**（缺少中断信息则无法正确解题）、**真实性**（采用自然的人类口吻）。
*   **轨迹锚定的中断模拟**：
    1.  首先生成无中断的完整轨迹。
    2.  根据相对进度（如 60% 处）动态注入中断消息。
    3.  智能体需根据更新后的意图继续执行，而不重置环境或进度。

#### 3. 实验设计
*   **数据集/场景**：基于 **WebArena-Lite**（包含 165 个经过人工验证的任务），涵盖 Reddit（社交）、GitLab（协作）、CMS（电商管理）、Map（地图）、OneStopShop（购物）五个领域。
*   **对比方法（模型）**：评估了六个强大的 LLM 骨干模型：**Claude-3.5-Haiku/Sonnet/Opus**、**Qwen3-Coder-480B-A35B**、**DeepSeek-V3.1** 和 **Mistral-Large-3**。
*   **评估指标**：
    *   **成功率 (SR)**：最终意图的达成情况。
    *   **预算限制成功曲线 SR(k)**：在中断后 $k$ 步动作内的成功率，衡量适应速度。
    *   **效率指标**：动作增量 ($\Delta A$) 和 Token 消耗增量 ($\Delta T$)。
    *   **多轮交互分析**：评估在 1-3 次连续中断下的表现。

#### 5. 实验数量与充分性
*   **实验规模**：对 165 个任务在 3 种中断类型、4 种中断位置（20%, 40%, 60%, 80%）以及多轮（最多 3 轮）设置下进行了详尽测试。
*   **充分性与公平性**：实验设计非常周密。通过引入“配对结果象限分析”（如 S/F, F/S 等），深入探讨了中断对成功和成本的具体影响。对比实验采用了相同的 Prompt 模板、工具接口和动作预算，确保了模型间比较的公平性。

#### 6 主要结论与发现
*   **适应性挑战**：即使是顶级模型，在处理中断时也面临巨大挑战。模型往往会陷入“陈旧假设”，无法将环境状态与新意图完全对齐。
*   **模型阶梯**：Claude 系列（尤其是 Opus）在一致性和单/多轮改进方面表现最强；开源模型（如 DeepSeek, Qwen）虽然有进步，但在多轮干预下表现不稳定，甚至出现性能倒退。
*   **效率代价**：处理中断的主要成本在于 **Token 开销（思考成本）**而非动作数量。在失败案例中，模型往往会进行冗长且无果的重新规划。
*   **位置敏感性**：大型模型在任务后期中断时表现更好（具备修复能力），而较小模型在任务早期中断时更容易成功。

#### 7. 优点（亮点）
*   **首创性**：填补了长程、有状态环境（网页导航）中可中断智能体评估的空白。
*   **现实性**：中断场景的设计（增加、修正、撤回）高度贴合真实用户行为。
*   **深度分析**：不仅关注成功率，还通过 SR(k) 曲线和 Token 效率分析了智能体的“思考”过程和恢复成本。

#### 8. 不足与局限
*   **环境重置限制**：实验假设环境状态在中断时是持久的，但在某些极端现实情况下，用户中断可能伴随着环境的外部变化，本文未涉及。
*   **模型覆盖**：虽然测试了主流模型，但未包含专门针对“可中断性”进行微调的模型，目前结果更多反映了通用模型的原生能力。
*   **评估成本**：由于网页导航任务的复杂性，大规模运行此类基准测试的 API 成本和环境维护成本较高。
